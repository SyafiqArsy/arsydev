# ArsyDev — Personal Portfolio & Technology Showcase

A personal portfolio website designed to showcase professional identity, technical skills, development experience, and software engineering projects.

**ArsyDev** represents a space to present my journey as a developer, highlight technical capabilities, and document projects and experiments across software development.

# 🇬🇧 English

## Overview

ArsyDev is a personal portfolio and technology showcase built to present my professional profile, technical expertise, development experience, and selected software projects.

The platform serves as a professional representation of my work and technical journey, particularly in backend development, full-stack engineering, and modern web technologies.

It is designed primarily for recruiters, companies, developers, and technology enthusiasts who want to explore my background, capabilities, and projects.

## Features

- **Personal Introduction** — Professional profile and background.
- **About Me** — Personal journey, interests, and development experience.
- **Technology Showcase** — Presentation of technical skills and technologies.
- **Project Showcase** — Selected software development projects.
- **Interactive Experience** — Modern animations, visual interactions, and 3D elements.
- **Responsive Interface** — Designed for different screen sizes.

## Technology Stack

The project currently uses the following technologies:

| Technology | Purpose |
|---|---|

## Getting Started

### Requirements

Make sure the following tools are installed:

- Node.js (LTS recommended)
- npm
- Git

### Installation

Clone the repository or open the project directory:

```bash
cd arsydev
```

Install dependencies:

```bash
npm install
```

### Development Server

Start the development server:

```bash
npm run dev
```

Open your browser and navigate to:

```text
http://localhost:3000
```

### Production Build

Build the application:

```bash
npm run build
```

Run the production server:

```bash
npm run start
```

## Available Scripts

| Command | Description |
|---|---|
| `npm run dev` | Start development server |
| `npm run build` | Build production application |
| `npm run start` | Start production server |
| `npm run lint` | Run ESLint |
